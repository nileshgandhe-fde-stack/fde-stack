# Seed Data

## Overview

`seed_enterprise_data.py` generates synthetic alerts, post-mortems, and tenant
SLA measurements for the AegisOps capstone. By default, its output is written
to this folder's `generated/` subdirectory.

## Business purpose

Repeatable synthetic data lets the API, analytics, and retrieval workflows be
developed and tested without relying on production incidents or customer
records.

## Key components

- `seed_enterprise_data.py` creates:
  - 1,000 PagerDuty/Prometheus-style alert records in `generated/alerts.jsonl`
  - 50 incident post-mortem Markdown files in `generated/postmortems/`
  - 10,000 tenant SLA measurements in `generated/tenant_sla.csv`
- `runbook/` contains three authored example runbooks used by the local
  project; they are not generated by the seed script.
- Generated post-mortems contain synthetic contact details. They are still
  treated as input to the redaction workflow before indexing.

## Generate data

From the capstone project directory:

```bash
python data_seed/seed_enterprise_data.py
```

For repeatable output, provide both a seed and a fixed timezone-aware reference
time:

```bash
python data_seed/seed_enterprise_data.py \
  --seed 42 \
  --as-of 2026-01-01T00:00:00Z
```

Use `--output-dir PATH` to write the generated artifacts elsewhere. The script
overwrites generated files with the same names in the selected output
directory.
